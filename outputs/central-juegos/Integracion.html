CENTRAL DE JUEGOS · API V1

Un registro para todos los juegos.

Este enlace reúne el protocolo para conectar juegos de distintas marcas a una sola planilla. No muestra participantes, celulares, claves ni resultados.

Conexión



Abrir el SDK común · Guardalo como platform-sdk.js. El SDK confirma cada recepción mediante Apps Script y no usa solicitudes opacas ni datos personales en URLs.


Antes de integrar
  1. Pedile al administrador un gameId propio y su gameKey de integración.
  2. Usá la marca y el nombre correctos. El administrador los mantiene en la pestaña Juegos.
  3. Pedí nombre y celular antes de jugar. Enviá el evento registration y esperá ok: true.
  4. Por cada ronda enviá game_started y luego game_completed o game_abandoned usando el mismo runId.
